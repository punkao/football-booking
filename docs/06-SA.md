## 3. Sequence — จองครั้งเดียว: เลือกช่วง → จ่าย → เช็กอิน

```mermaid
sequenceDiagram
  actor C as ลูกค้า
  participant W as เว็บ
  participant DB as ฐานข้อมูล
  actor S as พนักงาน

  C->>W: เลือกสนาม วัน เวลาเริ่ม จำนวนชั่วโมง ของเช่า
  W->>DB: อ่าน Booking ที่กันสนาม, Holiday, BookingRental, Customer
  W->>W: ตรวจ BR-02 ถึง BR-06, BR-16 แล้วคิดราคา BR-07 ถึง BR-12
  W-->>C: สรุปราคาแยกบรรทัด และ payNow
  C->>W: ชื่อ เบอร์โทร ยินยอม PDPA แล้วกดยืนยัน
  W->>DB: สร้าง Booking status PENDING_PAYMENT, payDeadline = ตอนนี้ + 15 นาที
  alt จ่ายทันกำหนด BR-10
    C->>W: จ่ายจำลอง (QR พร้อมเพย์)
    W->>DB: สร้าง Payment.method PROMPTPAY, Booking.amountPaid, status CONFIRMED
    W-->>C: รหัสการจอง Booking.code และ dueAtField
  else เลยกำหนด
    W->>DB: Booking status EXPIRED
    W-->>C: แจ้งหมดเวลา รอบนั้นว่างแล้ว
  end
  S->>W: ค้นด้วย Booking.code
  W-->>S: dueAtField
  S->>W: กด เก็บเงินแล้ว
  W->>DB: สร้าง Payment CASH_AT_FIELD, status CHECKED_IN, Customer.paidHours เพิ่ม BR-23
```

## 4. Sequence — ยกเลิก และปิดเพราะฝน (คืนเครดิต)

```mermaid
sequenceDiagram
  actor C as ลูกค้า
  actor O as เจ้าของ
  participant W as เว็บ
  participant DB as ฐานข้อมูล

  C->>W: ยกเลิก Booking.code
  W->>W: เหลือเวลาก่อน startHour กี่ชั่วโมง BR-13
  alt เหลือ 24 ชั่วโมงขึ้นไป
    W->>DB: Booking status CANCELLED
    W->>DB: CreditEntry reason CANCEL = amountPaid + creditUsed
    W->>DB: Customer.creditBalance เพิ่ม
  else น้อยกว่า 24 ชั่วโมง
    W->>DB: Booking status CANCELLED ไม่สร้าง CreditEntry
  end
  O->>W: ปิดสนาม A วัน ช่วงเวลา
  W->>DB: สร้าง FieldClosure
  W->>DB: ทุก Booking CONFIRMED ที่ทับช่วง เป็น RAIN_CLOSED
  W->>DB: CreditEntry reason RAIN ให้ Customer เจ้าของแต่ละการจอง BR-14 BR-15
```

## 7. Activity — คิดราคาและยอดจ่าย (BR-07 ถึง BR-12, BR-19, BR-22, BR-24)

```mermaid
flowchart TD
  A[ทุกชั่วโมงของการจอง] --> B{เสาร์ อาทิตย์ หรือ Holiday?}
  B -- ใช่ --> E[ใช้ Field.eveningRate]
  B -- ไม่ --> C{ชั่วโมงเริ่มตั้งแต่ 17:00?}
  C -- ใช่ --> E
  C -- ไม่ --> D[ใช้ Field.dayRate]
  D --> F[รวมเป็น fieldPrice]
  E --> F
  F --> G[discount 10 เปอร์เซ็นต์ ถ้าจองประจำได้จริง 8 สัปดาห์ขึ้นไป]
  G --> H[หักชั่วโมงฟรี ถ้า freeHourUsed]
  H --> I[บวก rentalPrice จาก BookingRental]
  I --> J[totalPrice]
  J --> K[หัก creditUsed ได้ไม่เกิน totalPrice]
  K --> L{เริ่มตั้งแต่ 17:00 วันศุกร์หรือเสาร์?}
  L -- ใช่ --> M[paymentPlan FULL_100]
  L -- ไม่ --> N[paymentPlan DEPOSIT_50]
  M --> O[payNow ปัดขึ้นเป็นบาทเต็ม และ dueAtField]
  N --> O
```
