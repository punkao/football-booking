## 1. บทนำ

### 1.1 วัตถุประสงค์
กำหนดความต้องการของเว็บจองสนามฟุตบอลหญ้าเทียม "ลูกหนัง อารีน่า" ให้ทีมสร้างเว็บ (เฟส 4) และทีมทดสอบ (เฟส 6–7) ใช้เป็นข้อตกลงเดียวกัน · รอบ 2 เพิ่มความสามารถ FR-32 – FR-48 โดยของรอบ 1 (FR-01 – FR-31) ต้องยังผ่านเหมือนเดิม

### 1.2 ขอบเขต
**รอบ 1:** ลูกค้าจองและจ่าย (จำลอง) เอง จัดการยกเลิก เลื่อน เครดิต จองประจำ ของเช่า สมาชิก หารค่าสนาม และหาทีมคู่แข่ง พร้อมหน้าร้านสำหรับพนักงาน ผู้จัดการ และเจ้าของ

**รอบ 2 เพิ่ม:**

| เรื่อง | ความต้องการ |
|---|---|
| แชทบอท "น้องบอล" ตอบข้อมูลร้าน ตรวจรอบว่าง/ราคา และจองให้ | FR-32 – FR-36 |
| คลังของ 2 ที่เก็บ และขายหน้าเคาน์เตอร์ | FR-37 – FR-41 |
| แดชบอร์ด ค้นการจอง รายงาน CSV | FR-42 – FR-44 |
| ติดตามสถานะการจองฝั่งลูกค้า | FR-45 |
| ดูแลข้อมูล: สำรอง/กู้คืน · audit log · migration | FR-46 – FR-48 |

**ไม่รวม:** ตาม `02-BA.md` ส่วนที่ 1 · แชทบอทไม่ยกเลิก ไม่เลื่อน ไม่คืนเครดิต และไม่ทำรายการหลังบ้าน (BR-32, NFR-17) · ไม่มีการจ่ายเงินจริง · ไม่ย้ายข้อมูลจาก LINE/สมุด

### 2.4 สภาพแวดล้อม
เว็บเบราว์เซอร์ Chromium / Firefox / WebKit (Safari) บนคอมพิวเตอร์และมือถือ · server รันด้วย docker compose บน Windows (NFR-14) · รอบ 2: `db/` กับ `web/` เป็น compose แยก คุยผ่าน network `football-net` และ `mock-llm` เป็น profile แยก (NFR-23) · ไฟล์ CSV ต้องเปิดใน Microsoft Excel ได้ (NFR-22)
