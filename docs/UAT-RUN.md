1. **[แก้ในใบแล้ว → "อาทิตย์ 25 ต.ค."] CR-05 หัวข้อก่อนตาราง** เขียน "ตั้งเวลาเครื่องทดสอบเป็น **เสาร์ 25 ต.ค. 2569 10:00**" แต่ 25 ต.ค. 2569 เป็น **วันอาทิตย์** (9 ต.ค. = ศุกร์ → 24 = เสาร์ → 25 = อาทิตย์; วันอื่นในใบ ส 31 ต.ค. · อา 1 พ.ย. · อ 3 พ.ย. · พ 28 ต.ค. · จ 2 พ.ย. ถูกหมด) → เสนอแก้เป็น "อาทิตย์ 25 ต.ค." (ทีมตั้งเวลาเป็น 2026-10-25 10:00 ตามตัวเลข ทุกขั้นจึงตรง)
2. **[แก้ในใบแล้ว] CR-04 ขั้น 9** ใบข้อ 9 ไม่ได้บอกว่าน้องบอลจะถาม PDPA เป็นข้อความก่อน และต้องพิมพ์ "ยินยอม" การ์ดยืนยันถึงจะขึ้น (ตรงกับ TC-CHAT-07) — ควรเติมในใบ: ... → น้องบอลถามยินยอม → พิมพ์ "ยินยอม" → ขึ้นการ์ด
3. **[แก้ในใบแล้ว] CR-05 ขั้น 8** ข้อ 8 ของใบเขียนให้เห็น "สัปดาห์ที่ 1 ฿1,200 · สัปดาห์ที่ 2–8 ฿1,300" แต่หน้าจอไม่ได้แสดงค่าสนามรายสัปดาห์ — แสดงเฉพาะยอดจ่ายตอนจองรายสัปดาห์ (฿540 / ฿585 = ครึ่งหนึ่งของ ฿1,080 / ฿1,170 หลังลด 10%) กับยอดรวมด้านล่าง · ควรแก้ใบเป็น "สัปดาห์ที่ 1 ฿540 · สัปดาห์ที่ 2–8 สัปดาห์ละ ฿585" แล้วคงยอดรวม ฿10,300 / ฿1,030 / ฿9,270
4. **[แก้ในใบแล้ว → 0.0%] CR-03 ขั้น 4** ใบเขียน "สนาม C 0 ชม. 0%" หน้าจอแสดง "0.0%" (ปัด 1 ตำแหน่งเหมือนสนาม A/B) — ไม่ผิด แต่ถ้าอยากให้ตรงตัวอักษรให้เขียน 0.0%
5. **CR-03 ขั้น 5** ใบให้ "เปิดด้วย Excel" และ "สูตรเดิมของร้านยังคำนวณถูก" — ทีมตรวจจากไฟล์ CSV (ชื่อ/ลำดับคอลัมน์ · BOM · ภาษาไทย) ซึ่งเป็นสิ่งที่สูตรอ้างถึง แต่ไม่ได้เปิดด้วย Excel จริงหรือสูตรของร้าน → ร้านต้องเปิดเองตอนตรวจ
6. **CR-03 ขั้น 6** ใบเขียน "ทีมแนบไฟล์เดิมให้" — รอบนี้ไม่มีไฟล์รายงานก่อนปรับระบบที่แนบให้ร้านจริง ทีมเทียบกับ golden master `tests/golden/side.golden.json` (case `report/2026-10-03..2026-10-09`) แทน · ก่อนส่งร้านต้องแนบไฟล์เดิมจริง หรือเขียนในใบว่าเทียบกับตัวเลขชุดไหน
7. **CR-01 ขั้น 7 · CR-05 ขั้น 9 · CR-06 ขั้น 10** เป็นขั้น "หลังขึ้นระบบจริง" ที่ทำบนเครื่องทดสอบไม่ได้ครบ (ต้องมี cookie รุ่นเก่า / ยอดก่อน-หลังขึ้นระบบจริง / คำท้าเดือนเก่าของร้าน) → เสนอย้ายไปเป็นรายการตรวจใน RUNBOOK ตอนขึ้นระบบ หรือคงไว้ในใบโดยบอกร้านชัดว่าทีมทำตอนขึ้นระบบ
