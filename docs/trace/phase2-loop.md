# Trace · เฟส 2 (BA + User Story) — Loop Template

ใช้ Loop Template จาก `Teaching_CWN2026/01_Basic_AI_WORFLOW/labs/prompts/loop/loop-template.md`
บทบาท GENERATOR และ CRITIC ทำโดย session หลัก (จำลองบทบาท ไม่ใช่ agent อิสระ — ระบุตามจริงแบบบทเรียน 1.4)
สูงสุด 3 Iteration · หยุดเมื่อผ่านครบ หรือเกณฑ์เดิมไม่ผ่าน 2 ครั้งติดโดยไม่ดีขึ้น

## REQUIREMENT

จาก `docs/01-INTERVIEW.md` (v2) เขียน
1. `docs/02-BA.md`: stakeholder, รายการคำพูดต้นทาง S-xx, As-Is (เท่าที่มีหลักฐาน), To-Be process (Mermaid), pain point → ความสามารถ, gap, คำถามที่ยังไม่ชัด
2. `docs/03-USER-STORIES.md`: User Story "ในฐานะ… ฉันอยาก… เพื่อ…" รหัส US-xx · เกณฑ์ยอมรับ 1–3 ข้อ · Must/Should/Could · ตาราง S-xx → US-xx · คำถามที่ยังไม่ชัด
ภาษาใน story เป็นภาษาลูกค้า ห้ามศัพท์โปรแกรม (database, API)

## CRITERIA (ล็อกก่อน Iteration 1 — ห้ามแก้ระหว่าง Loop)

- **C1 ครบต้นทาง:** คำพูดทุกข้อ S-xx ใน `02-BA.md` ถูกอ้างในตาราง S→US ของ `03-USER-STORIES.md` อย่างน้อย 1 US และทุก US อ้าง S-xx ที่มีอยู่จริง (ตรวจด้วย `tools/check-phase2.mjs`)
- **C2 ตรวจได้:** ทุก US มีเกณฑ์ยอมรับ 1–3 ข้อ และทุกข้อมีตัวเลข หรือข้อความในเครื่องหมายคำพูด "…" หรือผลที่สังเกตได้ชัด (ทำได้/ไม่ได้) (สคริปต์ตรวจจำนวน + ตัวเลข/คำพูด; CRITIC อ่านข้อที่ไม่มีตัวเลข)
- **C3 ไม่แต่งตัวเลข:** ค่าที่เป็นกฎ (฿, เวลา HH:MM, %, จำนวน + หน่วย) ใน 02 และ 03 ต้องมีอยู่ในบทสัมภาษณ์ ถ้าเป็นค่าที่คำนวณต้องอยู่ในบรรทัดที่แสดงที่มา (มี `=` หรือ `×`) · ไม่ตัดสินเรื่องที่สัมภาษณ์ไม่ได้บอก ให้เก็บเป็นคำถาม (สคริปต์ตรวจตัวเลข; CRITIC อ่านเรื่องการตัดสินแทนร้าน)
- **Mermaid** ใน `02-BA.md` ต้อง render ได้จริง (ตรวจด้วย `tools/render-mermaid.mjs` บน Chromium)
