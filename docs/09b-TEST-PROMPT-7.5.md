## 2. เขียน test และรัน
1. เขียน TC ใหม่ใน `e2e/tests/` ตามโมดูล (test ที่เลื่อนเวลา → `*.serial.spec.ts`) · ใช้ `getByTestId` ตาม SPEC เท่านั้น
2. รัน `npm test` ทั้งชุด 2 รอบ · ข้อที่ล้ม: ดูภาพ/trace ก่อน แล้วจัดเป็น เว็บผิด / test เขียนผิด / กฎไม่ชัด / flaky · แก้ได้เฉพาะ test ที่เขียนผิดจริง
3. `npm run test:gif` → ทุก test ที่เปิดหน้าเว็บมี .gif และ .mp4
4. ก่อนรันใหม่ให้ย้าย `e2e/test-report/TEST-REPORT.md` ปัจจุบันไปเป็น `TEST-REPORT-before-7.5b.md` · รายงานใหม่คือ `TEST-REPORT.md`
