## ฟิลด์ที่ตัดออก / แปลงก่อนเทียบ (และเหตุผล)

| อะไร | ทำอย่างไร | เหตุผล |
|---|---|---|
| HTTP header ทุกตัว (`date` `set-cookie` `etag` `content-disposition` …) | ไม่เก็บ เก็บแค่ status + content-type + body | `date` เปลี่ยนตามนาฬิกาจริงของเครื่อง · cookie มีลายเซ็น HMAC ของ session ไม่ใช่พฤติกรรมธุรกิจ |
| cookie ที่ได้จาก login | ใช้ส่งต่อ ไม่บันทึก | เป็นข้อมูลยืนยันตัวตน ห้ามอยู่ใน repo |
| body ของ `/api/quote` | **ไม่ตัดฟิลด์ใดเลย** | ไม่มี id ที่รัน / เวลาสร้าง · `rentals[].remaining` คงที่หลัง reset · พิสูจน์ด้วยรัน 3 รอบ (2 รอบติด + หลัง rebuild) ได้ไฟล์เดียวกัน |
| `availability.now` `today` `maxDate` | **เก็บไว้** | มาจาก `app_settings.clock` ที่ reset ล็อก ไม่ใช่นาฬิกาเครื่อง · ถ้าวันไหนไม่นิ่ง = seam นาฬิกาเสีย ซึ่งอยากให้จับได้ |
| CSV | แยกเป็นรายการบรรทัด + ธง `bom` `crlf` | diff อ่านง่าย · อ่านไบต์เองด้วย `TextDecoder({ignoreBOM:true})` เพราะ `fetch().text()` ตัด BOM ทิ้งเงียบ ๆ |
| ลำดับ key | เรียงตามตัวอักษรทุกชั้น | ให้ sha8 คงที่แม้ลำดับ key ใน JSON ของเว็บเปลี่ยน |
