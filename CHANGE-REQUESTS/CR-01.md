# หนังสือขอเปลี่ยนแปลงระบบ ฉบับที่ 1/2569

| | |
|---|---|
| เลขที่ | CR-01 |
| วันที่ | 20 ตุลาคม 2569 |
| เรื่อง | ออกจากระบบแล้ว ยังเข้าใช้ต่อได้ |
| เรียน | ทีมดูแลระบบจองสนาม |
| ความเร่งด่วน | **ด่วน** |

น้องพนักงานยืมคอมเคาน์เตอร์เข้าหลังบ้านแล้วกด "ออกจากระบบ" ไปแล้ว แต่ทีมทดสอบบอกว่าถ้ามีใครเก็บ cookie เดิมไว้ ยังเปิดหน้าร้านและข้อมูลการจองได้อยู่ ฝั่งลูกค้าสมาชิกก็เป็นเหมือนกัน (ดูข้อมูลสมาชิก เครดิต ชั่วโมงสะสมได้)

- กด "ออกจากระบบ" แล้ว ต้องใช้ต่อไม่ได้จริง ทั้งบัญชีร้านและบัญชีสมาชิก
- คนที่ไม่ได้กดออกจากระบบ ใช้งานต่อได้ตามปกติ ไม่ต้องเข้าสู่ระบบใหม่ทุกคน
