# หนังสือขอเปลี่ยนแปลงระบบ ฉบับที่ 6/2569

| | |
|---|---|
| เลขที่ | CR-06 |
| วันที่ | 21 ตุลาคม 2569 |
| เรื่อง | เงินค่าสนามจากทีมที่รับคำท้า ไม่ขึ้นในรายงาน (เรื่องที่ทีมดูแลระบบพบระหว่างทำ CR-03) |
| เรียน | ทีมดูแลระบบจองสนาม |
| ความเร่งด่วน | ปกติ (ทำหลัง CR-05) |

ทีมดูแลระบบแจ้งว่า เวลาทีมคู่แข่งรับคำท้าแล้วโอนเงินส่วนของทีมตัวเอง ระบบบันทึกเป็นเครดิตให้เจ้าของการจองอย่างเดียว ไม่ได้บันทึกว่าร้านรับเงินเข้ามา เงินก้อนนี้จึงไม่ขึ้นในรายงานยอดเงินเลย ร้านกระทบยอดกับบัญชีแล้วไม่ตรง

- เงินที่ทีมรับคำท้าโอน ต้องขึ้นในรายงานยอดเงินด้วย
- รายงานเดือนก่อน ๆ ก็ต้องถูกด้วย
- เครดิตที่เจ้าของการจองได้ ให้เหมือนเดิม
