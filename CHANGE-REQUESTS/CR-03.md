# หนังสือขอเปลี่ยนแปลงระบบ ฉบับที่ 3/2569

| | |
|---|---|
| เลขที่ | CR-03 |
| วันที่ | 20 ตุลาคม 2569 |
| เรื่อง | รายงานยอดแยกช่องทางเงิน และชั่วโมงใช้สนาม |
| เรียน | ทีมดูแลระบบจองสนาม |
| ความเร่งด่วน | ปกติ |

ทุกสิ้นเดือนร้านต้องกระทบยอดเงินเข้าบัญชีพร้อมเพย์กับเงินสดในลิ้นชัก แต่รายงานตอนนี้รวมเป็น "ยอดจอง" ก้อนเดียว ต้องมานั่งแยกเองจาก CSV

- รายงานช่วงวัน (หน้าเว็บ **และ** ไฟล์ CSV) ขอแยกเงินค่าสนามเป็น **มัดจำ/จ่ายผ่านพร้อมเพย์** กับ **เก็บหน้าสนาม** (A-41)
- ขอดู **ชั่วโมงที่ใช้ของแต่ละสนาม** A B C ในช่วงที่เลือก เป็นชั่วโมงและเปอร์เซ็นต์ (A-42)
- ยอดอื่นที่มีอยู่แล้ว (ขายหน้าเคาน์เตอร์ หักเครดิต ฯลฯ) ให้คงไว้เหมือนเดิม ไฟล์เดิมที่ร้านทำสูตร Excel ไว้แล้วอย่าให้พัง
