# หนังสือขอเปลี่ยนแปลงระบบ ฉบับที่ 2/2569

| | |
|---|---|
| เลขที่ | CR-02 |
| วันที่ | 20 ตุลาคม 2569 |
| เรื่อง | แก้ 5 จุดให้ตรงกับที่ร้านตอบไว้ |
| เรียน | ทีมดูแลระบบจองสนาม |
| ความเร่งด่วน | ปกติ |

ทีมทดสอบถามร้านมาหลายข้อ ร้านตอบไปแล้ว (บันทึกใน `docs/01-INTERVIEW.md` A-41–A-50) แต่ระบบยังทำไม่ตรง ขอแก้ 5 จุดนี้

1. **เช็กอิน** พนักงานต้องเช็กอินได้เฉพาะ **วันเตะ** เท่านั้น ตอนนี้กดล่วงหน้าได้ แล้วชั่วโมงสะสมของลูกค้าขึ้นทันที (A-45)
2. **ประวัติสถานะ** ช่อง "ใครกด" ต้องเป็น **ชื่อพนักงาน** ไม่ใช่ชื่อบัญชี (A-44)
3. **ติดตามการจอง** เมื่อเล่นเสร็จแล้ว ต้องมีขั้น **"จบ"** เป็นขั้นสุดท้าย (A-43)
4. **รายงานช่วงวัน** เลือก 30 พ.ย. ถึง 28 ก.พ. แล้วระบบบอกว่าเกิน 3 เดือน ร้านนับว่าได้ (A-46)
5. **ค้นการจอง** ลูกค้ากดค้นโดยยังไม่กรอกอะไร ขึ้นว่า "เกิดข้อผิดพลาดในระบบ" ลูกค้าตกใจ ควรบอกให้กรอกข้อมูล
