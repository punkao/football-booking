# หนังสือขอเปลี่ยนแปลงระบบ ฉบับที่ 4/2569

| | |
|---|---|
| เลขที่ | CR-04 |
| วันที่ | 20 ตุลาคม 2569 |
| เรื่อง | น้องบอลจำเรื่องที่คุยไปแล้ว |
| เรียน | ทีมดูแลระบบจองสนาม |
| ความเร่งด่วน | ปกติ |

ลูกค้าบ่นว่าคุยกับน้องบอลแล้วต้องพิมพ์ใหม่ทั้งประโยคทุกครั้ง เช่น ถามว่า "พรุ่งนี้ 19:00 สนาม A ว่างไหม" แล้วถามต่อว่า "งั้นสนาม B ล่ะ" น้องบอลตอบว่าไม่มีข้อมูล

- ในห้องแชทเดียวกัน ถ้าลูกค้าถามต่อโดยไม่บอกวัน เวลา หรือสนามซ้ำ ให้น้องบอลใช้สิ่งที่คุยไว้ก่อนหน้า (US-39 · FR-35)
- ถามว่า "ช่วงไหนถูกสุด" ให้ตอบเป็นช่วงราคา เช่น ก่อน 17:00 วันธรรมดา ฿800/ชม. (A-48) แล้วถามต่อว่า "ถ้าเอาช่วงนั้น 2 ชั่วโมงล่ะ" ต้องคิดราคาได้
- ภาษาอังกฤษก็ต้องจำได้เหมือนกัน
- เรื่องอื่นของน้องบอลให้เหมือนเดิม (การ์ดยืนยันก่อนจอง ปฏิเสธนอกเรื่อง ปิดเบอร์ ฯลฯ)
