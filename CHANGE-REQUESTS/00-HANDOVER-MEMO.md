## 2. วิธีเปิดระบบ

```bash
docker compose -f db/compose.yaml up -d
docker compose -f web/compose.yaml up -d --build
```

- เว็บ: http://localhost:3000 · ฐานข้อมูล: localhost:5433
- ต้องตั้ง `SESSION_SECRET` ใน `web/.env` ก่อนเปิด (ดู RUNBOOK 2.0)
- รีเซ็ตข้อมูลทดสอบได้ที่ `POST /api/test/reset` · **ในการใช้งานจริงให้ปิด** (`ALLOW_TEST_RESET=0`)

## 3. ผลการทดสอบก่อนส่งมอบ

- ชุดตรวจกฎร้าน **ผ่าน 191/191** · ตรวจตาม TEST-DATA **ผ่าน 151/151** · unit **88/88**
- ชุดทดสอบหน้าเว็บของทีมทดสอบอิสระ: **117/128 ทุกเบราว์เซอร์** — ข้อที่ไม่ผ่านอยู่ใน `e2e/triage.json`
- ระบบกันการจองซ้อนที่ระดับฐานข้อมูล · ยอดเงินเป็นจำนวนเต็มบาท · ประวัติสถานะและบันทึกการทำงานแก้ย้อนหลังไม่ได้

## 4. ข้อจำกัดที่ทราบ

- แชทบอทจองได้เฉพาะการจองพื้นฐาน (ของเช่า เครดิต ชั่วโมงฟรี จองประจำ → ให้จองหน้าเว็บ)
- ขีดจำกัดแชทต่อ IP เชื่อ `X-Forwarded-For` ตัวแรก (ยังไม่มี reverse proxy)
- โหมดฝังบั๊ก `BUG_MODE=1` ใช้เพื่อฝึกทดสอบเท่านั้น
